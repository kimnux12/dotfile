블루투스 키보드가 검색되지 않는 문제를 해결하기 위해 다음 단계를 시도해 볼 수 있습니다.
1. 블루투스 모듈 상태 확인

블루투스 모듈이 제대로 로드되었는지 확인합니다.

lsmod | grep bluetooth

2. 블루투스 서비스 상태 확인

블루투스 서비스가 제대로 작동 중인지 확인합니다.

sudo jounalctl -u bluetooth
sudo systemctl status bluetooth

3. 블루투스 장치 리셋

블루투스 모듈을 리셋합니다.

sudo systemctl restart bluetooth

4. 블루투스 장치가 제대로 작동하는지 확인

블루투스 장치가 하드웨어적으로 문제가 없는지 확인합니다. 다른 장치에서 해당 블루투스 키보드를 검색해 보세요.
5. Bluetoothctl 명령어 사용
sudo pacman -S bluez bluez-utils
sudo groupadd bluetooth
sudo usermod -aG bluetooth $USER
user usermod -aG lp $USER
rfkill list
sudo rfkill unlock bluetooth

bluetoothctl
power on
agent on
default-agent
scan on
trust
pair
connect

이 명령어들을 순서대로 입력한 후, 블루투스 장치 목록에 키보드가 나타나는지 확인합니다.
6. rfkill 상태 확인

블루투스가 소프트웨어나 하드웨어적으로 차단되어 있는지 확인합니다.

sh

rfkill list

만약 블루투스가 차단되어 있다면, 차단을 해제합니다.

sh

sudo rfkill unblock bluetooth

7. 블루투스 관련 패키지 확인 및 재설치

블루투스 관련 패키지가 제대로 설치되어 있는지 확인하고, 필요하다면 재설치합니다.

sh

sudo pacman -S bluez bluez-utils

8. 블루투스 펌웨어 업데이트

블루투스 어댑터의 펌웨어를 최신 버전으로 업데이트합니다. 특정 어댑터 모델에 따라 다르므로, 어댑터 제조사의 지침을 따르세요.
9. 추가 로그 확인

블루투스 관련 로그를 확인하여 추가적인 오류 메시지를 찾아냅니다.

sh

sudo journalctl -u bluetooth

10. 블루투스 모드 재설정

키보드를 페어링 모드로 설정한 후 다시 검색을 시도해 보세요. 많은 블루투스 키보드는 특정 키 조합으로 페어링 모드에 진입합니다. 키보드의 사용자 매뉴얼을 참고하여 페어링 모드로 진입해 보세요.
11. 커널 모듈 및 설정 확인

필요하다면, 커널 모듈과 설정을 확인하여 블루투스 모듈이 제대로 로드되었는지 확인합니다.

sh

sudo dmesg | grep -i bluetooth

위의 단계들을 하나씩 시도해 보면서 블루투스 키보드가 검색되지 않는 문제를 해결할 수 있습니다. 문제가 계속될 경우, 사용하는 블루투스 어댑터 모델과 구체적인 환경 설정에 대한 추가 정보를 제공해 주시면 더 자세한 도움을 드릴 수 있습니다.
