* Org mode에 sourc block 넣기

1. C-c C-, 입력후 원하는 형식의 단축키 넣기

2. < + 원하는 단축키 + TAB
#+begin_quote
단축키 유형:
        n - notes
        a - export ascii
        c - center
        C - comment
        e - example
        E - export
        h - export html
        l - export latex
        q - quote
        s - src
        v - verse
#+end_quote
