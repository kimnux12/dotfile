* org문서의 in-buffer설정
doom emacs에서 ox-hugo를 이용해 markdown으로 변환시킬 것이기 때문에
org문서의 in-buffer에 적는 metadata에 다음을 반드시 추가해야한다.
#+begin_example
#+HUGO_BASE_DIR: /home/kimnux/Homepage
#+HUGO_SECTION: post
#+end_example
위에서 Homepege는 새 프로젝트로 사용할 디렉토리이고,
post는 /home/kimnux/Homepage/content/post의 post이다.
* 새 프로젝트 생성
#+begin_src
hugo new site Homepage
#+end_src
* hugo.toml 설정
#+begin_src bash
cd Homepage

vi hugo.toml
#+end_src

#+begin_example
baseURL = 'https://kimnux12.github.io/'
languageCode = 'en-us'
title = 'Linux에 관한 주저리 주저리'
theme = 'hugo-clarity'
#+end_example
* 선택한 테마를 설치하고 git 서브모듈 등록하기
#+begin_src bash
cd ~/Homepage
git init
git submodule add https://github.com/chipzoller/hugo-clarity.git themes/hugo-clarity
#+end_src
* 새 포스트 작성하기
#+begin_src bash
hugo new post/test.md
#+end_src
* hugo 서버 실행
#+begin_src bash
cd ~/Homepage
hugo serve
#+end_src
-D 옵션은 draft:true로 설정되어 있을 경우를 대비하기 위함.

* 깃허브 원격저장소에 hugo website 올리기
** 빌드하기
#+begin_src bash
cd ~/Homepage
hugo
#+end_src
** kimnux12.github.io를 로컬 저장소로 클론하기
#+begin_src bash
git clone https://kimnux12:token@github.com/kimnux12/kimnux12.github.io.git
#+end_src
token은 github에 저장소를 만들때 부여받은 각자의 token.
사용자명과 github주소는 각자의 것들을 기입해야한다.
** public 폴더의 내용을 clone 받은 폴더로 옮기기
#+begin_src bash
mv ~/Homepage/public/* ./kimnux12.github.io
#+end_src
** kimnux12.github.io 원격저장소로 push하기
#+begin_src bash
cd ./kimnux12.github.io
git add .
git commit -am 'adding all the content'
git push
#+end_src
추후 새로운 글을 작성하면, 빌드하고 ./kimnux12.github.io로 복사(cp -r)하고 push하면 된다.
